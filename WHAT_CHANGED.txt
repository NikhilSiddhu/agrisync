AgriSync public dashboard
=========================

    cd ~/agrisync
    unzip -o ~/agrisync_dashboard.zip
    pytest -q            # expect 85 passed

WHAT IT IS
  dashboard/            its own Flask app on port 8080, separate from the API
  dashboard/data.py     read-only Mongo queries, hard 7-day public cap
  dashboard/templates/  the page, using agrisync.tech's exact design tokens

WHY A SEPARATE SERVICE
  dashboard.agrisync.tech is public. api.agrisync.tech is behind Access.
  One process serving both hostnames would let anyone request an API path on
  the public hostname and bypass Access. Separate port, HTML only.

INSTALL
  cd ~/agrisync
  sed -e "s|User=pi|User=$USER|" -e "s|Group=pi|Group=$USER|" \
      -e "s|/home/pi/AgriSync|$PWD|g" deploy/agrisync-dashboard.service \
      | sudo tee /etc/systemd/system/agrisync-dashboard.service
  sudo systemctl daemon-reload
  sudo systemctl enable --now agrisync-dashboard
  curl localhost:8080/health

ROUTE IT
  cloudflared tunnel route dns --overwrite-dns agrisync dashboard.agrisync.tech
  sudo nano /etc/cloudflared/config.yml

  ingress:
    - hostname: api.agrisync.tech
      service: http://127.0.0.1:5000
    - hostname: dashboard.agrisync.tech
      service: http://127.0.0.1:8080
    - service: http_status:404

  sudo systemctl restart cloudflared

  Do NOT add a Cloudflare Access application for dashboard.agrisync.tech.

ON YOUR SIDE
  Point the hero "Dashboard" button in agrisync.tech's index.html at
  https://dashboard.agrisync.tech
