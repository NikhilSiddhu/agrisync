AgriSync 1.3.0 — USB serial bridge
==================================

    cd ~/agrisync
    unzip -o ~/agrisync_serial.zip
    source .venv/bin/activate && pip install pyserial
    pytest -q            # expect 60 passed

NEW
  scripts/serial_bridge.py            reads [payload] lines from the ESP32 over
                                      USB and POSTs them to the local API
  deploy/agrisync-serial-bridge.service
  tests/test_serial_bridge.py         11 tests, no serial port needed

CHANGED
  firmware/.../main.cpp               USE_WIFI_POST flag. Set 0 = tethered mode:
                                      no WiFi, no NTP, no buffering, no retries
  firmware/.../platformio.ini         version 1.3.0, USE_WIFI_POST=1 by default
  requirements.txt                    + pyserial
  README.md, progress.md              docs

TO USE IT
  1. edit platformio.ini, set -DUSE_WIFI_POST=0
  2. reflash (exports still needed for DEVICE_API_KEY; WIFI_* are ignored)
  3. install and start the bridge service
  4. journalctl -u agrisync-serial-bridge -f

  Stop the bridge before any reflash, or the upload cannot open the port.

BEFORE THE BOX GOES OUTSIDE
  Set USE_WIFI_POST back to 1, or move to the A7670C over the tunnel.
